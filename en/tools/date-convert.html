Format Info

ISO format (YYYY-MM-DD) is an international standard commonly used in programming and data storage. Unix timestamp represents the number of seconds elapsed since January 1, 1970 00:00:00 UTC. ISO week number is calculated based on the international standard (ISO 8601), where Monday is the start of the week.
